# Patas Amigas

Site institucional de uma ONG fictícia de resgate e adoção de cães e gatos, feito para a 2ª nota da disciplina de Introdução à Computação.

## Seções
- Início
- Sobre Nós (causa e equipe)
- Nossos Projetos
- Galeria
- Como Doar
- Contato

## Estrutura
```
index.html
css/style.css
imagens/        fotos (hero, sobre, equipe, projetos, galeria)
icones/         logo e ícones das redes sociais em SVG
```

## Tecnologias
HTML5 semântico e CSS3 com design responsivo (`@media` para tablet e celular). Todas as mídias estão salvas localmente.

Fotos: [Unsplash](https://unsplash.com).
